# DIVYAASTRA — The World's Greatest Spiritual Sanctuary

A spiritual e-commerce marketing site for sacred Hindu products, built with TanStack Start and deployed on Netlify. Features a curated catalog of 38+ consecrated pooja items, healing stones, and sacred objects — all framed around the Divyaastra Foundation's mission to build the world's tallest Shiva temple.

## Tech Stack

- **Framework**: TanStack Start (SSR React)
- **Router**: TanStack Router v1 (file-based routing)
- **Build**: Vite 7
- **Styling**: Tailwind CSS 4 + custom CSS (gold/green spiritual theme)
- **Fonts**: Cinzel Decorative, Cinzel, Cormorant Garamond (Google Fonts)
- **Language**: TypeScript 5.7 (strict mode)
- **Deployment**: Netlify

## Running Locally

```bash
npm install
npm run dev        # Dev server on http://localhost:3000
npm run build      # Production build
npm run preview    # Preview production build
```

Or with Netlify CLI for full platform emulation:

```bash
netlify dev        # http://localhost:8888
```
